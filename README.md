# open-conto-annuale — Il personale della PA italiana, aperto e interrogabile

> **Quante persone lavorano nella PA? Quanto costano? Quali retribuzioni? Assenze, età, titoli di studio.**

open-conto-annuale nasce dai dati del **Conto Annuale** della Ragioneria Generale dello Stato (MEF — OpenBDAP).
Abbiamo pulito, normalizzato e reso pubblici i dati sul personale di tutte le pubbliche amministrazioni italiane.

## 🟢 Interroga i dati via clean-query (MCP)

I dataset sono accessibili tramite il server MCP **clean-query** del DataCivicLab.
Collegalo al tuo client con la configurazione standard del Lab.

## 📦 I dati in breve

| Cosa | Quanto |
|---|---|
| **Enti coperti** | ~13.000 (comuni, ASL, università, regioni, ministeri, enti) |
| **Periodo** | dal 2001 |
| **Macro-aree** | occupazione, retribuzioni, assenze, personale, flessibili, contrattazione |
